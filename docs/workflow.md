# 从书籍到学习使用

本流程是项目设计，不表示所有环节已经自动实现。

1. 确定书籍版本、任务和范围。没有具体应用场景时可以先看全书。
2. 阅读全部可见内容，核对重要图表和注释，记录缺损及疑点。
3. 评价作者已有结构。清楚的部分沿用，必要时局部整理或重组。
4. 核对每个重要主张与关系的来源，再反查重要原文是否有学习入口或明确省略理由。
5. 给出概览、方法说明、术语解释及原文定位。可视化是呈现方式，不能代替结构质量。
6. 按使用者的任务选择学习重点，先给能读懂的简短说明。
7. 为对应的方法准备练习，分别核对任务要求和评价依据。
8. 用户提交实际尝试；缺口集中反馈，按需给提示、解释或示范，再让用户尝试。
9. 使用者有真实任务时，实际应用并保留过程及结果。没有机会就明确尚未验证。
10. 复盘已有表现、仍缺的证据和下一步。

提示和示范后的表现、没有本题针对性提示的新任务表现、真实应用和后续保持分别记录。练习设计有错时先修资料，不把问题归为使用者能力不足。

当前版本首先提供结构化 Skill 与模拟示例。通用 EPUB 处理、网页生成和完整学习记录产品仍在路线图中。
