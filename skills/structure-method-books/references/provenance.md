# 方法来源与边界

版本：0.1.0-trial，2026-10-16。由项目《结构化方法规范-双书草案-v0.4》压缩成可执行指引。规则编号保持 R01—R07。

## 两本参考书的贡献

黎甜《结构化思维》：模型按任务选择，明确问题与中心，分组与关系、顺序、适用边界及核查。重点研究第四章及相关模型、边界段落。已解析全文文本，不等于逐字精读所有案例、核验全部图片。

芭芭拉·明托《金字塔原理》：问题与回答对应，同组思想回答同一问题，概括必须有实质含义；行动概括直接结果、描述概括共同含义；区分演绎、归纳、顺序及推测。重点研究第2、3、5、6、7章相关内容并结合其他章节与附录，核看五幅关键图；未逐字精读所有案例、核验所有图片。

前者明确引用明托，重合处不是两份独立效果验证。它们主要讨论思考和表达，不直接提供 Agent 拆整本书的完整方案；本 Skill 含项目改编。

## 项目约定与复核经验

- 用户要求：优先沿用好结构，必要时再修或重组；整本交付前读完可见原书；结构质量优先于导图。
- 项目设计：双向覆盖、节点与练习关联、版本及当前状态分开管理。
- 《刻意练习》Q01—Q09复核经验：不能把重要方法只藏在附件；保留失败对照、解释桥梁和先备关系；区分声音、主张与证据状态；重要关系使用专用来源；不把引用多当覆盖好。
- Q10经验：每条重要条件明确限定谁，避免把分支条件提升为父节点所有主张的前提。

Q01—Q10在该书v0.4的指定复核范围内已关闭。被复核稿件中的“待复核”是历史状态，项目伴随记录“当前验证状态.json”给出闭环状态。关闭已知问题不保证没有其他问题。

Skill 不包含该书的特定节点、六步归纳流程或某领域训练标准。试跑同一本书只是熟悉材料上的执行检查，自查不能冒充独立盲测。跨书适用性和用户学习效果仍需另行验证。
