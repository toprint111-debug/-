# 把大任务变成可执行的一步

这是为演示本项目而原创的模拟方法材料，不是出版书籍摘录，也不声称其效果已经验证。

<a id="p01"></a>
## P01：要解决的问题

“整理好资料”这类目标有时太宽，使人不知道马上要做什么。这份短文讨论如何把它变成一个可观察的下一步。

<a id="p02"></a>
## P02：先说明这一步产生什么

先写清本轮要留下的具体结果。例如把一组资料按日期归档后，能够根据日期找到对应文件。资料范围要明确。

<a id="p03"></a>
## P03：选择直接产生该结果的动作

围绕结果安排动作。若本轮只处理一个文件夹，就把分类规则写出来，再按规则处理这部分文件，而不把所有资料同时列为本轮任务。

<a id="p04"></a>
## P04：用结果检查，再决定下一步

操作后按预先说明的找文件任务检查。若找不到，应查明是哪条分类规则或哪步处理产生问题，再调整规则或动作。这个返回调整的过程可以重复。

<a id="p05"></a>
## P05：适用边界

这段演示假定任务结果和检查依据可以明确。如果缺少专业判断依据，先补可靠依据或寻求合适指导，不能随意给一个正确率就算解决。
