# Book Method Lab · 方法书学习实验室

把方法类书籍整理为能查原文、看清关系、继续练习的学习资料。当前是早期试用项目。

**当前为早期试用版 `0.1.0-trial`，以 MIT 许可开放。**

## 现在可以使用什么

- `structure-method-books`：已有的结构化 Skill，含七组检查规则、交付约定和方法来源说明。
- 一份原创模拟材料及对应结构示例，方便先了解工作方式。
- 学习流程、项目状态、路线图和贡献说明。

Skill 需要由能够读取文件的 Agent 执行。它不是一个独立运行的拆书软件；当前仓库没有一键导入 EPUB、自动生成网页或自动评分的通用程序。

## 先试一个小例子

1. 阅读[原创模拟材料](examples/original-mini-guide.md)。
2. 将本仓库文件提供给能够读取本地资料的 Agent，发送下面这段请求。
3. 用[结构示例](examples/structured-demo.md)比较整理范围、关系及来源。示例不是唯一答案，也不是学习效果证明。

> 请阅读 skills/structure-method-books/SKILL.md 及其适用的 references。用 examples/original-mini-guide.md 做一次明确标注为“模拟短文”的结构化整理。先判断作者已有结构，再选择沿用或局部整理；给出主要回答、具体方法、关系、条件和段落依据。缺依据的地方直接说明，不补造原文，不宣布练习有效。

## 用自己的书

使用自己有权使用的本地书籍。先确定版本和阅读范围，核对正文及重要图片，再整理方法、关系与条件。来源定位与内容判断都需要检查；摘录数量不能代替质量。

阅读[学习流程](docs/workflow.md)和[能力边界](docs/status.md)。原书、全文摘录、个人学习记录和生成的私人资料留在本地。

## 当前状态

Skill 版本为 `0.1.0-trial`。已有特定书籍个案的试用与局部复核经验；跨书泛化、独立使用、学习效果和通用程序尚未完成验证。私有研究材料未放入此候选稿，公开读者不能仅凭这段说明复现原个案复核。

欢迎反馈具体问题与可复现例子，参见[贡献说明](CONTRIBUTING.md)。不要在公开 Issue 中提交未经授权的原书全文或个人学习记录。
